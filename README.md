# Take-Home Midterm 2026/1 — Bangkok CCTV Vehicle Detection

Kaggle: https://www.kaggle.com/competitions/2110531-dsde-2026-1

## Setup
```bash
conda create -n dsde python=3.12 -y
conda activate dsde
pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
kaggle competitions download -c 2110531-dsde-2026-1 -p data/raw   # then unzip into data/raw
```

## Run
Open `vehicle_detection.ipynb` (kernel `Python 3.12 (dsde)`) from this folder and run all cells.
Settings are in the **Config** cell; each can also be set by an environment variable of the same name
(`MODEL, IMGSZ, EPOCHS, BATCH, FULL_TRAIN, SKIP_TRAIN, WEIGHTS, TTA, RUN_NAME`).
Outputs: `runs/<run>/` (weights, curves) and `submissions/<run>.csv` + `.json` (settings and val score).

Batch run without opening Jupyter (Git Bash):
```bash
IMGSZ=960 BATCH=4 EPOCHS=40 jupyter nbconvert --to notebook --execute vehicle_detection.ipynb --output experiments/yolo26s_960_executed.ipynb
```

Quick pipeline check (1 epoch, 10% of data): `SMOKE_TEST=1`.

Reproduce a submission from saved weights (no training):
```bash
SKIP_TRAIN=1 WEIGHTS=weights/yolo26s_960_full.pt IMGSZ=960 TTA=1 RUN_NAME=repro jupyter nbconvert --to notebook --execute vehicle_detection.ipynb --output experiments/repro_executed.ipynb
```

## Results (validation = 4 held-out cameras 1066, 1427, 1437, 244; pycocotools mAP@50)

| Run | Val mAP@50 |
|---|---|
| yolo26s, 640 | 0.4666 |
| yolo26s, 640 + TTA | 0.4919 |
| yolo26s, 960 | 0.4958 |
| yolo26s, 960 + TTA | **0.5247** |
| yolo26s, 960, all 15 cams, 25 ep + TTA (final) | – (no held-out val) |

`experiments/postproc_eval.py` compares MAX_DET 100/300 and TTA on the val cameras.

## Folder layout
```
vehicle_detection.ipynb   main pipeline (EDA, cleaning, split, train, eval, visualise, submit)
requirements.txt
experiments/              executed notebooks + logs of every run, postproc_eval.py
submissions/              submission CSVs + JSON with settings/val score
report/                   build_report.py, results.json, figures/, midterm_report.docx/.pdf
data/raw/                 Kaggle data (not in git)
data/yolo/                YOLO-format dataset generated by the notebook from data/raw (not in git; zipped on Google Drive,
                          its .txt lists contain absolute paths of the author machine - re-run the notebook to rebuild)
runs/                     Ultralytics runs, weights (not in git -> upload to Google Drive)
```
